# Projet Minishell

🇫🇷  
**Minishell** est un projet qui consiste à créer un shell minimaliste, capable d’interpréter et d’exécuter des commandes en ligne de commande. L’objectif est de comprendre le fonctionnement d’un shell, la gestion des processus, des redirections, et des variables d’environnement.

Ce shell supporte les commandes basiques, les pipes, les redirections d’entrée et de sortie, ainsi que la gestion des signaux. Ce projet permet d’approfondir les notions de programmation système et de gestion des processus sous Unix.

---

🇬🇧  
**Minishell** is a project that involves creating a minimalist shell capable of interpreting and executing command line instructions. The goal is to understand how a shell works, process management, redirections, and environment variables.

This shell supports basic commands, pipes, input/output redirections, and signal handling. This project helps to deepen knowledge in system programming and process management on Unix systems.
